En mi proyecto se ven quise implemetar una tienda basica de video juegos a gusto personal, los cuales estan distribuidos de acuerdo a su valor aproximado en el mercado y una forma hipotetica de como pueden adquirirse para plataforma de PC principalmente si todos estos pudieran jugarse en esa plataforma. En el index se puede ver de manera basica videos cargados de manera local, sin usar links de plataformas para evitar que el codigo se vea demasiado extenso. 

Las imagenes fueron descargadas directamente desde google y estas presentan una transisión basica entre el momento en que no se seleccionan y al momento de colocar el mouse encima la cual resalta de manera luminosa eliminando la sombra de la imagen. Los audios y videos no tienen una mejora directamente visual o transisión para evitar hacerlos mas pesados pero si tienen modificaciones en CSS para hacerlos agradables a la vista. En cuanto a las tablas; estas muestran el listado de juegos. El formulario de la pagina permite que los usuarios que visiten puedan realizar pedidos o consultar disponibilidad de juegos. Tambien fechas de entrega.

El usuario tambien podra generar un registro de su información para la creación de usuario y asi poder tener acceso de manera personalizada a la información de la tienda, donde podra comprar sus juegos y tener un historial de compras. Esto se guardará en la base de datos del backend para poder ser manipulada por el administrador a cargo.
